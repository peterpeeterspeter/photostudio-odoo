Generate product images from Odoo

Ghost mannequin, flatlay, on-model, lifestyle, photoshoot, detail, and marketplace export — created from your existing Odoo product photos and written back to the product.

External service. Image generation requires connection to the external Photostudio.io service and valid API credentials. The Odoo module itself installs and runs without an activation key. The API key authenticates to the Photostudio Jobs API and does not unlock or license this addon. Photostudio credits are billed separately, not by Odoo.

What it does

  • Ghost mannequin, on-model, lifestyle (core set)
  • Flatlay, photoshoot, detail, marketplace export
  • Batch wizard with credit estimate and replace-main confirmation
  • Jobs list, polling cron, optional signed webhooks
  • Writeback to product templates and variants

What it does not do

  • It does not run AI models on your Odoo server
  • It does not include Photostudio credits or hosting
  • Marketplace export is a canvas reframe, not a full marketplace listing

Track job status and writeback in Odoo

Data sent to Photostudio

When you confirm generation, the module sends:

  • Selected product or variant main image
  • Extra gallery images when that option is enabled
  • Job options such as operation, pose, scene, background prompt, and optional model catalog id

Photostudio returns generated image files that Odoo downloads and stores on the product. The wizard requires explicit confirmation before the first upload of a batch.
